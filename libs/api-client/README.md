# api-client

Typed HTTP client for the Mockp REST API (`@mockp/api-client`).

Phase 5 scaffold only (subtask 5.2): this library has no public API yet.
The generated types, the `openapi-fetch` client and the contract scripts
arrive in later subtasks — see `docs/IMPLEMENTATION_ROADMAP.md` (Fase 5)
and `docs/adr/009-openapi-contract-and-api-client.md`.

## Building

Run `nx build api-client` to build the library.

## Running unit tests

Run `nx test api-client` to execute the unit tests via
[Vitest](https://vitest.dev/) (none yet).
